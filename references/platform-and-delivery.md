# Platform delivery and handover

## Plan for the destination

Confirm the destination platform and intended placement (Shorts, standard YouTube video, trailer, lesson, social clip, etc.) before choosing output dimensions. Do not assume every YouTube upload is vertical or short-form.

Plan the following per project:
- aspect ratio and resolution;
- frame rate;
- safe areas for titles, captions, and UI;
- thumbnail composition and title treatment;
- subtitle/caption format;
- language and accessibility needs;
- export codec/container and audio settings;
- chapter markers for long-form videos where useful.

## Deliverables

Depending on scope, provide:
- final video export;
- editable project/source files that the local tools created;
- final script and pronunciation guide;
- storyboard/animatic and shot list;
- source register, claim ledger, bibliography, and credits;
- subtitle file (for example SRT or VTT) when requested or supported;
- thumbnail and platform metadata draft;
- production/QA report.

Never claim a source project is editable if only a flattened MP4 exists. Never include API keys, private source files, unlicensed media, or personal data in a public release bundle.

## YouTube metadata

Write an accurate title, description, chapters, and tags. Do not use misleading claims, fake quotations, invented expertise, or sensational titles that contradict the video. Include source links and corrections/contact information when appropriate. Clearly identify dramatizations and illustrative visuals.
