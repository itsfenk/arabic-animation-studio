# Story and script frameworks

There is no single mandatory formula. Pick the structure that fits the content, audience, and duration.

## Available approaches

- **Documentary/explainer:** question → context → evidence → explanation → implications → takeaway.
- **Chronological story:** setup → turning points → consequences → what is known today.
- **Character-led narrative:** character goal → obstacle → choices → consequence, using only documented facts for real people.
- **Investigation:** question → evidence trail → competing explanations → what the evidence supports → open questions.
- **Educational lesson:** learning objective → intuitive example → explanation → demonstration → recap.
- **Heritage/folktale:** provenance → story version → cultural meaning → variants/uncertainties.
- **Fiction:** premise → characters → conflict → escalation → resolution; clearly distinguish fiction from factual claims.
- **What If/speculative:** explicit premise → rules/assumptions → consequences → real-world constraints → conclusion. Keep modeled assumptions separate from scientific facts.

## Script construction

1. Define one central viewer promise and one takeaway.
2. Decide the narrator's point of view, tense, tone, and level of detail.
3. Outline sections before writing dialogue.
4. Give every scene a visible purpose; each narration line should add information, emotion, or transition.
5. Match the amount of information to the intended duration. Estimate aloud, then revise after a real voice sample.
6. Build transitions logically; avoid using cliffhangers to imply facts that are not established.
7. Add source/claim IDs to factual lines in the working script, not necessarily on screen.
8. Review for repetition, unsupported causality, ambiguity, and misleading compression.

## Duration and pacing

Do not hard-code 15–25 seconds or a fixed words-per-minute target. Estimate narration duration from a short sample with the chosen voice, then add time for visual comprehension, pauses, title cards, and sound moments. Short-form content needs a clear hook and one primary idea; long-form content needs chapters, context, evidence depth, and pacing variety.

## Dramatic reconstruction

For real historical or religious subjects, do not write invented dialogue or inner thoughts as facts. Use narrator-led transitions or clearly marked fictionalized scenes only when the content class and user brief allow it. Religious content remains governed by the stricter dedicated policy.
